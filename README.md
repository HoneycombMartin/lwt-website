# Light Weight Technology — Official Website

Official website of Light Weight Technology Pvt Ltd, Thirumazhisai, Chennai — paper honeycomb manufacturing since 2009.

Paper honeycomb packaging buffers, boards, thermal insulation panels, Vistara storage racks and partition wall panels — 100% recyclable, plastic-free replacements for thermocol, EPS and timber.
